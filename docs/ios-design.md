# Cuven max（iOS）设计规范：依据 Apple Human Interface Guidelines

所有界面改动先查 Apple 文档、有出处再动手。出处编号：

- **F1–F90**：[docs/hig/foundations.md](hig/foundations.md)（布局、字体、颜色、深色、材质与 Liquid Glass、动效、图像、无障碍、品牌与文案）
- **T1–T40 / D1–D18 / I1–I14 / S1–S24**：[docs/hig/tvos-and-duo.md](hig/tvos-and-duo.md)（tvOS 设计语言、iPhone Duo 的约束、iOS 通用规则、把 tvOS 搬到触屏上的做法）
- **C 编号**：组件与模式（标签栏、工具栏、列表、弹层、菜单、搜索、引导、隐私、播放），见 [docs/hig/components.md](hig/components.md)

每条规则都附了 Apple 原文的短引文和页面 › 小节。

## 原则

1. **内容在前，界面退后**：画面铺满，字和控件只在需要时出现；品牌不占内容的位置，不放口号、印章、法务行（F1、F80、T1）。
2. **一套设计随屏幕长大**：折起和展开是同一套 tvOS 式的语言（铺满的头图、一排排海报、画面里轻轻的视差），展开只是更大——更大的头图、每排更多的卡、更从容的留白；不另做一个「展开模式」（S1、D2、D3、I11）。
3. **玻璃只在功能层**：标签栏、导航栏、工具栏、少数浮在画面上的控件；卡片、货架、文字面板一律不用玻璃（F38–F46）。
4. **分组靠留白**：不画描边、不垫底板、不用分隔线分区；同一种间距贯穿全 App（F3、F12）。
5. **系统字、语义色**：一律用系统文字样式（Large Title … Caption 2），层级靠字重和 `.secondary`；强调色只给一个主操作和状态（F15–F19、F28、F32、F33）。
6. **动效有目的**：头图翻页（画面比字慢一点）、卡里画面极轻的视差（约 2%）、按下去略缩的触感、系统的推入 / 缩放转场；卡在排里不放大、不压暗别的卡（用户要求，安静优先：F61）；「减弱动态效果」打开时视差、自动翻页都停（F52–F61、S12、S17）。
8. **卡上只有画面**：无字的主视觉 + 官方字标，或本来就印着片名的海报；卡下不写片名（用户要求：片名由画面上的字标交代，T20；只给旁白念，F75）。字标在所有卡上一样高、太宽的按卡宽收。
7. **文案短而平实**：按钮用动词（播放、继续播放），不写「我们」，空状态告诉人下一步（F84–F88）。
9. **不写影片计数**（用户要求「全局所有界面不应该有影片计数和相关信息，移除它们」）：哪里都不写「N 部影片」「共 N 部」「N 个结果」「N 张剧照」「全 N 集 / 更新至第 N 集」这类数量，也不写「高于片库里 N% 的电影」这类拿片库来比的话。年份页只有大标题、没有副标题；账户页「继续观看」「想看」两行只有名字；搜索「全部」上面那行是「「…」的搜索结果」；剧照卡的小字是「剧照」；剧集的「影片详细信息」和搜索结果不写集数。「第 N 集」「第 N 季」「第 N 幕」是在说哪一集、哪一季、哪一张，不算计数，照旧。

## 字与层级（设计轮 1：字体与信息层级）

同一种角色只用一种字、一种颜色；令牌都在 `Design.swift`（`Font.ds…`、`DSInk`），新写的字从这里取，不再各写各的（F15、F18、F19）。

| 角色 | 令牌 | 样子 | 用在哪 |
|---|---|---|---|
| 展示标题 | `Font.dsDisplay(wide:)` | 36 / 44 点特粗（压在画面上，字跟着那一块画面的大小走，所以是定值） | 「编辑推荐」、精选区和合集页的「精选电影」等大标题 |
| 大一级的分区标题 | `Font.dsShowcaseTitle(wide:)` | 折起 Title 1、展开 Large Title，粗体（S4：展开时上一级） | 只给主页年份那两排「2026 ›」 |
| 分区标题 | `Font.dsSectionTitle` + `DSSectionLabel` | Title 2 粗体，折起、展开一样；有去处时后面一个「›」（Title 3 半粗、`DSInk.tertiary`，旁白不念） | 主页每一排、「为您的口味量身定制的内容 ›」、详情页的「简介」「剧集」「预告片」「剧照」「演员 ›」「影片详细信息」「更多××电影 ›」、演员页、资料库「剧照」、搜索结果、账户的组名 |
| 分区副标题 | `Font.dsSectionSubtitle` | Body 常规、`DSInk.tertiary` | 「今年上映的新片与新剧」「向左滑动查看更多」 |
| 长正文 | `Font.dsReading` | Body、松行距（F21：三行以上不用紧行距） | 详情页五行简介、演员页「关于」、资料库的简介、简介弹层 |
| 第二行 / 一行信息 | `DSInk.secondary` | 白 72% | 头图和详情页头部的「类型 · 年份 · 片长」、分集卡和预告片卡的「▶ 45 分钟」与小字、剧照卡上的小字、年份卡 / 精选卡 / 合集卡 / 编辑推荐面板里片名下面那一行、精选区的说明、资料库的副标题与简介 |
| 更轻的一级 | `DSInk.tertiary` | 白 55% | 分区副标题、标题后的「›」 |

这一轮改了什么（before → after）：
- **分区标题只剩两级**：以前一页上有五种——折起时主页的「继续观看」和几个大类是 Title 3 半粗（20 点），详情页的「剧集」「预告片」「剧照」「演员」也是，可同一页的「简介」「影片详细信息」「更多××」是 Title 2 粗体（22 点），两种交替出现；「为您的口味量身定制的内容」折起 Title 2、展开 Title 1（28 点），和上面 44 点的「精选电影」抢；年份那两排 Title 1 / Large Title。现在普通的分区标题一律 Title 2 粗体（App Store、游戏 App 的分区标题；折起 20 → 22 点，「为您的口味…」展开 28 → 22 点），只有年份那两排大一级（折起 28、展开 34 点不变）。详情页的组名也换成同一个部件，整行可点（以前只有字那一截能点）。（F18、F19、S4）
- **「›」一个样子**：以前 15 点半粗灰、20 点粗体 50% / 55% / 60% 白四种，现在跟着标题大小走（分区标题后面 Title 3 半粗、年份标题后面 Title 2 半粗），颜色都是 `DSInk.tertiary`，旁白不念（标题本身就是链接）。
- **副标题一个样子**：年份那两排的灰字从 Title 3（20 点）收成 Body（17 点），「2026」更突出；「向左滑动查看更多」从 Headline 半粗换成 Body 常规（副标题不该比正文还重）。颜色 50% → 55% 白。
- **灰字三级**：同是片名下面那一行，以前年份卡 55%、精选卡 62%、合集卡 72%、编辑推荐面板 78%、分集卡 78%、剧照卡 85%、头图 80% 白，现在都是 `DSInk.secondary`（72%）；年份卡那一行亮了一些（55% → 72%），在黑底上更好读。没动的：详情页卡里的字（`DetailPalette.ink2`，带这一页的颜色，参考图如此）、精选大卡上的灰字「Cuven 独占」（用户要求）、资料库画幅正中压在预告片上的那一行（85%，压在视频上要更亮）、账户页（自成一套，55%）、系统列表里的 `.secondary`。

## 动效与反馈规范（用户要求：所有交互、按钮、元素都有动效和视觉反馈，同一套规范）

同一类东西动起来是同一个手感，数都从 `DSMotion`（`Motion.swift`）取，新写的动效不再各写各的数（F52–F61）：

| 令牌 | 曲线 | 用在哪 |
|---|---|---|
| `DSMotion.press` | 弹簧 0.28 秒、阻尼 0.68 | 所有能点的东西按下去：卡片、按钮、分区标题链接、名单的一行、侧边导航的格子（`PressableStyle`：略缩到 0.90–0.98、略暗 6%，松手带弹性回来） |
| `DSMotion.snap` | snappy 0.26 秒 | 小切换：开关、符号替换（＋ ↔ ✓、播放 ↔ 暂停）、选中的那块滑过去（搜索的「全部 / 电影 / 剧集」、侧边导航） |
| `DSMotion.appear` | 弹簧 0.5 秒、阻尼 0.86 | 出现 / 消散：从略小、略糊里弹出来；一排的卡数变了（演员作品查到了）跟着长出来 |
| `DSMotion.hero` | 弹簧 0.6 秒、阻尼 0.82 | 大块进出：钉住的条从上面滑下来、演员页的名字和三颗钮、立体海报弹开 |
| `DSMotion.fade` | 缓入缓出 0.4 秒 | 颜色和画面：取色的底慢慢染上、预告片出画面时从模糊里淡入 |

- **按压**：能点的都有按压反馈；玻璃的（`.glassEffect(.interactive())`）用系统自带的玻璃回弹，不再叠一层缩放。
- **触感**：换标签一下选择触感（系统标签栏和侧边那一列一起，`sensoryFeedback(.selection)`）；选中的那块换了（搜索分类）一下选择触感；
  主按钮（演员页的 ▶、圆钮）一下轻触感，符号同时弹一下（`symbolEffect(.bounce)`）；加入 / 移出想看一下选择触感、符号替换。
  触感只给「选了 / 做了」，滚动、翻页不给（F41）。
- **出现**：图片、字标第一次载入从一点点模糊里淡入（不带方向）；整页的颜色取到了再慢慢染上，不闪；卡片在排里不放大、不压暗（用户早先的要求）。
- **视频**：全 App 同一时刻只放一段预告片（`TrailerFocus`）；主页年份那两排不自动放，按住才放、松手就停（用户要求，见「主页」）；出画面时从模糊里淡入；不在屏上、换页、正片盖上来就停。码流（HLS 档位）够清楚才露、不够就停在清楚的静态画面上：年份卡要 900 像素高的档位，放了 10 秒还没到降到六成（540；以前 540 起、降到 324 就露，360p 的码流放大两倍多，用户截图里年份卡的画面糊成色块）；露出来以后码流又掉到下限以下超过两秒，淡回静态画面，等它再升上去。
- **减弱动态效果**（F59）：弹簧、推镜、浮动、视差、海报墙的横移一律停，只留短淡入（`DSMotion.adapt`）。
- **帧率**：Info.plist 打开 `CADisableMinimumFrameDurationOnPhone`，ProMotion 屏上自定义动画跑到 120Hz；
  持续动画（海报墙横移、立体海报浮动）只在屏上时跑，滑走就停，不在后台一直占着渲染。
  主页结尾的海报墙第一次滑到才建（之前先占住同样的高）：主页这一列不是懒加载的，以前一启动就连同下载把那六十张海报做了，
  占了启动时一半的图片视图（CI 诊断：头一秒 265 次图片渲染）。
- **顶栏一律渐进式模糊，不许有硬边界线**（用户要求）：系统导航栏底下的滚动边缘全用柔和的那种（`dsSoftTopEdge()` = `.scrollEdgeEffectStyle(.soft, for: .top)`，
  主导航栈的每一页和每个弹层的导航栈 `SoftNavigationStack` 都挂上）——以前账户页顶上是系统「硬」的那种：一块实色底 + 一条硬边（用户截图）。
  自己画的顶栏用 `DSProgressiveBar`：两层磨砂 + 这一页的颜色从上往下淡掉，条底下多淡出一截，没有底线、没有影子——
  详情页钉住的那一条（以前是带色磨砂 + 0.5 点底线 + 影子）、账户页滚过头部以后顶上那一截（`AccountTopBar`：左边 30 点圆头像 + 名字，
  和下面那一列卡左边对齐，用户要求「这个位置换成头像 + 名字」；系统那一行只留关闭钮，它底下的滚动边缘不画，免得两层叠着）。
- **下拉刷新**（`settledRefreshable`，主页、资料库）：转圈至少转 0.8 秒、等手松开了才收。刷新瞬间就做完的时候（演示数据、没网立刻失败），
  系统在手还按着时收它，转圈会卡在「刷新中」再也不走、整页被顶下去一截（CI 折叠屏截图里卡了半个小时）。
- **播放失败的说明**（F87）：常见的几种按错误码说清楚（`PlayerErrorText`）：屏幕放不了这种画面格式（4K / HDR，外接显示器、隔空播放）、
  设备解不了这种编码、网络断了、连接超时；认不出来的才用系统那句。
- **iPhone Duo 各种形态**：折起（窄屏，导航在侧边那一列）、展开（宽屏，一行两三张）、半折（窗口高被压矮）都按窗口的宽高排，不认机型：
  大块的高度都按窗口高封顶（编辑推荐最多 82%：折起约宽的 1.3 倍、展开竖拿 0.9 倍、横着 0.56 倍，底图先按这一块摆好再裁——竖版主视觉按 fill 铺会比块高，以前多出来的那截盖在上面那排精选卡的下半截上；演员照片最多 72%、头图 86% / 94%），合集页、年份那两排、演员作品按可用宽度变列数 / 卡宽。

  - 自动调整怎么测：
    - 网络情况来自系统的 `NWPathMonitor`：连没连上、Wi‑Fi / 有线 / 蜂窝、是不是按流量计费（蜂窝、个人热点）、是不是开着低数据模式。
    - 速度打 Worker 的测速探针 `/api/edge/ping`（随机字节、不缓存，网页版「优选入口」测速用的同一个）。先三次空请求量延迟，取最快的；再下载 256 KB 起，每级 ×4，按流量计费的最多 1 MB、别的最多 4 MB。哪一级花了 2 秒以上就够准了；一级 8 秒没下完，按「最多这么快」算。测速下的字节记进流量概览。
    - 低数据模式不测速，演示数据不连网（只按网络类型估）。
  - 怎么选百分比：

    | 网络 | 速度 | 百分比 |
    |---|---|---|
    | 低数据模式 | — | 20%（省流量，预告片不自己放） |
    | 任何网络 | 不到 3 Mbps | 20%（带宽留给正片） |
    | 按流量计费（蜂窝、个人热点） | 25 Mbps 以上 / 10 以上 / 再慢 | 60% / 50% / 40%（缓冲够用，中途不看了白下的少） |
    | 不计费（Wi‑Fi、有线） | 25 Mbps 以上 / 10 以上 / 再慢 | 100%（交给系统）/ 90% / 75% |
    | 探针不通 | — | 只看网络类型：计费的 45%，不计费的 90% |
  - 什么时候重测：换了网络（类型、计费、低数据模式变了）等 2 秒再测；回到 App 时上次测的超过半小时也重测；只在 App 在前台时测。
  - 存在哪：自动选的数存在本机另一个键（`cuven_network_speed_auto_value`，开关是 `cuven_network_speed_auto`）。手动设的那个数照旧和网页版同步，不会被这台手机此刻的网络带着走；服务器读回来的值也不会盖掉自动选的。
  - 手动拖滑块、旁白上下轻扫就是要自己定：自动调整关掉，拖到的数是新的手动值。按「已开启」关掉时停在现在的数上：自动选的数变成手动设的，像关掉自动亮度。
  - 卡下一行在开着时多一句「换网络或隔半小时回到 App 会重新检测」。

## iPhone Duo 展开（tvOS 风格）
- 不是另一套界面：同一套部件按 `DSMetrics` 长大（S1、D2）——头图更大、每种卡按目标宽排（屏越宽一排放得越多，卡不会比折起时小：Duo 展开竖拿四张多、横拿五张半海报）、年份那两排的标题和压在画面上的展示标题上一级字号（普通的分区标题折起展开一样，设计轮 1）、边距与间距按 tvOS 比例（S3–S6），排与排之间按屏高收一收。
- 系统栏由系统摆（D5–D7）：展开竖拿是横向的栏，横拿和外屏在侧边一列；画面在栏下延伸（F6、S19）。
- 一处有意的偏离（用户要求）：折起（横竖都算）和展开横拿时，系统把标签栏竖进侧边那一列，搜索和别的格挤在一枚胶囊里、SwiftUI 拆不开；这几种形态下收起系统标签栏，在那一列里自己画一枚竖向 Liquid Glass 胶囊（主页 / 资料库，只有图标，选中那格垫一块更亮的玻璃、滑过去）和下面单独一颗搜索圆钮（`DuoNav.swift`）——和 iOS 26 横着的标签栏把搜索拆出来是同一个样子。导航栏、工具栏和返回仍是系统的；展开竖拿和别的 iPhone 仍是系统标签栏（偏离 D7）。
  收起系统标签栏靠两层：每一页都挂 `duoHidesTabBar()`（SwiftUI 的 `.toolbar(.hidden, for: .tabBar)`），再加一层 UIKit 的 `TabBarGuard`——每一页出现、转完屏、形态一变，都看一眼 `UITabBarController`，该藏没藏就藏，不是这几种形态却藏着就放出来。修（用户截图：展开横拿，详情页右下角侧边导航和系统标签栏错开叠成两份）：详情页里点演员推进的演员页以前没挂 `duoHidesTabBar()`，一进去系统标签栏就回来了，回到详情页也不再藏；只靠 SwiftUI 那一层，转屏、展开 / 合上以后也可能被带回来。
- 展开时卡更大、间距更宽（卡间距至少 24），视差按卡宽算（S12）；头图铺满到侧边那一列底下（F6）。
- 全屏视频（正片、全屏预告片）展开时跟着设备转、竖拿也能看；折起和别的设备一律横屏（用户要求，见「弹层、欢迎、隐私、播放加载」里的「全屏视频的方向」）。
