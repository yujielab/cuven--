# Cuven max（iOS）设计规范：依据 Apple Human Interface Guidelines

所有界面改动先查 Apple 文档、有出处再动手。出处编号：

- **F1–F90**：[docs/hig/foundations.md](hig/foundations.md)（布局、字体、颜色、深色、材质与 Liquid Glass、动效、图像、无障碍、品牌与文案）
- **T1–T40 / D1–D18 / I1–I14 / S1–S24**：[docs/hig/tvos-and-duo.md](hig/tvos-and-duo.md)（tvOS 设计语言、iPhone Duo 的约束、iOS 通用规则、把 tvOS 搬到触屏上的做法）
- **C 编号**：组件与模式（标签栏、工具栏、列表、弹层、菜单、搜索、引导、隐私、播放），见 [docs/hig/components.md](hig/components.md)

每条规则都附了 Apple 原文的短引文和页面 › 小节。

## 原则

1. **内容在前，界面退后**：画面铺满，字和控件只在需要时出现；品牌不占内容的位置，不放口号、印章、法务行（F1、F80、T1）。
2. **一套设计随屏幕长大**：折起和展开是同一套 tvOS 式的语言（铺满的头图、一排排海报、画面里轻轻的视差），展开只是更大——更大的头图、每排更多的卡、更从容的留白；不另做一个「展开模式」（S1、D2、D3、I11）。
3. **玻璃只在功能层**：标签栏、导航栏、工具栏、少数浮在画面上的控件；卡片、货架、文字面板一律不用玻璃（F38–F46）。
4. **分组靠留白**：不画描边、不垫底板、不用分隔线分区；同一种间距贯穿全 App（F3、F12）。
5. **系统字、语义色**：一律用系统文字样式（Large Title … Caption 2），层级靠字重和 `.secondary`；强调色只给一个主操作和状态（F15–F19、F28、F32、F33）。
6. **动效有目的**：头图翻页（画面比字慢一点）、卡里画面极轻的视差（约 2%）、按下去略缩的触感、系统的推入 / 缩放转场；卡在排里不放大、不压暗别的卡（用户要求，安静优先：F61）；「减弱动态效果」打开时视差、自动翻页都停（F52–F61、S12、S17）。
8. **卡上只有画面**：无字的主视觉 + 官方字标，或本来就印着片名的海报；卡下不写片名（用户要求：片名由画面上的字标交代，T20；只给旁白念，F75）。字标在所有卡上一样高、太宽的按卡宽收。
7. **文案短而平实**：按钮用动词（播放、继续播放），不写「我们」，空状态告诉人下一步（F84–F88）。

## 各页

### 主页
- 头图 `DSHeroCarousel`：竖着的屏约 86% 屏高、用竖版全屏图，横着的屏 94% 屏高（S15；用户要更沉浸），下面露出下一排的标题。画面连同 iPhone Duo 侧边那一列一起平铺，系统栏 / 导航浮在画面上（F6、S19）。左上一行白色大字「Home」（Apple TV 主页那样的大标题，跟着头图滚走：C13），同一行右边一枚头像（玻璃圈里的圆头像，点开账户与设置的弹层；用户要求从侧边导航里分出来，像 App Store 右上的账户钮）。最多 5 部，每一部都要拿到无字的背景（Apple TV 的无字背景，没有就 TMDB 没有字的剧照）和字标才上——画面上本来印着片名的不用，免得和字标叠成两份（用户要求）。画面不接点按，只有「详情」进详情页，详情页仍从这张画面上放大出来、返回时缩回（T31、F57）。
- 分区（只靠留白分开）：继续观看（有才有；16:9 画面 + 字标 + 进度）→ 今年 → 去年（电影和剧集的海报一起，最新入库的在前，标题「2026 ›」进年份页）→ 精选电影、精选剧集（用户要求，照 Apple「游戏」App 的合集页；卡底那条磨砂条偏离 F38「内容不用玻璃 / 半透明」，大卡横滑时仍不放大、不压暗别的卡：`FeaturedCollection`——一条由黑浮上来、再沉回黑的染色带，带上三张立体海报封面（`Poster3D`：正面海报 + 往右下错开的深色厚度 + 由亮到暗的斜边 + 左上高光 + 柔影，斜着叠成一扇），弹开、浮动、视差三种动效（弹开等第一次滑进屏幕才放，浮动只在屏上时跑；减弱动态效果时都停：F59）；大号粗体标题 + 一段说明；一排大卡（整幅画面 + 底下磨砂条：小海报、片名、「Cuven 独占 · 类型」、「查看」），标题「›」进全部；电影的门槛和头图一样，剧集要有海报和剧照，一部剧只出一次）→ 五个大类：引人入胜的剧情、令人坐立难安、科幻和奇幻之旅、动作演员就位、刺激犯罪与偷窃（电影和剧集一起，按 TMDB 类型认，标题「›」进这一类的全部）。文件夹一排挪到搜索页。
- 去掉：今日推荐、最新加入、剧集三排与「新」角标，卡下的片名、名次与灰字，滑动时的放大与压暗（用户要求；F3、F38、F80）。

### 详情（电影 / 剧集）
- 头部一样高（竖着 90%、横着 92% 屏高），画面连同侧边那一列平铺，底边收在字标上沿（`DetailHeroBackdrop`：裁好、最下面那一截渐进式模糊——画面高的 76% 起糊、到底边糊满并化进取自底边的主色，模糊正好落在字标上方那条线上，用户要求；F6、F34、C58），画面和字标只定一次、模糊淡入、不再换（`DetailArt`；字标用透明底的模糊淡入，不会先闪一块黑框），左对齐：字标、一行信息（类型 · 年份 · 片长 · ★评分）、播放 + 一颗「…」系统菜单（从头播放、复制直链、分享）（F1、F34、S17、F50）。
- 下面照用户给的参考图（Apple「游戏」App 的详情页；用户要求，偏离 F38「内容不用玻璃 / 半透明」）：整页染上头部画面底边的主色（`DetailPalette`：头部字下面那一截是它、往下慢慢沉到同色相的深色），一组一行粗体标题（Title 2）+ 一张圆角 34 的半透明卡（10% 白、14% 白细边），卡里的次要字是带这个颜色的浅色：简介卡（五行简介，点开是从卡上放大出来的系统弹层：C50、F57；分隔线下「导演」一行，大号首字圆章）→ 分集 → 预告片 → 演员 → 影片详细信息卡（左边一列大号评分 + 五颗星 / 描边徽章「4K」「GB」「ZH」/ 大符号，右边一行带颜色的字：评分、类型、年份、片长、画面、声音、大小与文件名，行间细线，最底下居中「在 TMDB 中查看 ↗」）→ 「更多××电影 ›」卡（同类型的三部：海报、片名、年份 · 类型、「查看」胶囊，整行点进详情，标题点进这一类的全部）。往上滚过「播放」，顶上钉住一条同色的条（小海报、片名、玻璃「播放」胶囊），从上面滑下来（弹簧；减弱动态效果时只淡入）；导航栏里不再写片名（偏离 C12，条里有）。卡滑进屏幕时从 97% 长到原大、淡入。
- 去掉：「尖端色彩和画面质量技术」与「语言」两块玻璃卡、法务一行、品质保证、「第 N 幕」（F38、F80、F84）。

### 资料库
- 和网页版的展映同一套逻辑（用户要求，网页版的内容也一并带回来）：只放有预告片的电影——预告片就是详情页那一份 Apple TV 公开预告；上映新的在前，全片库查完一轮后首尾相接。满屏画幅、钉住、收回 16:9（跟着手指走：F54、S10），屏幕中间那一章用它的预告片作背景视频：静音，右上角有看得见的暂停钮（F77），系统「自动播放视频预览」关着就不自己放（S17）。
- 每章：画幅里一行「年份 · 类型 · 片长」+ 字标（F34：一层均匀压暗，字走了还画面一个干净的满屏）；下面的介绍面板照网页版：简介、评分、导演与主演、「播放」「影片详情」两颗等宽钮（C35、C36）、一排剧照（停在左边线上、右边露出下一张一截：S8），章间一道两头渐隐的细线。章高跟着面板走（原来按画幅的行程定高，面板短的那一章底下空出一大块黑）。
- 标题「资料库」+ 一句「Cuven 为你提供严格品质的影片」压在第一章的画面上、随页面滚走（F15、F19）。
- 还在查的时候只有一个系统转圈（C69）；查完一部都没有、断网时用系统空状态说清下一步，带一颗钮（F87、F88）。

### 搜索 / 年份 / 文件夹
- 搜索：系统搜索栏与大标题；没输入是「文件夹」一排和「最近添加」海报网格，输入了（用户要求，照 Apple TV 的搜索和网页版）上面一排胶囊分类「全部 / 电影 / 剧集」；「全部」里剧集一排 16:9 横卡、电影一排竖海报（卡型不同，一眼分得出），最相关的那一类在前（T23、F4、C61、C63）；「电影」「剧集」是带缩略图、片名、一行灰字和「•••」菜单的列表（C45、C51、F74）；没结果用系统的空状态（F87）。
- 年份页：系统大标题 + 副标题「N 部影片」，下面一张海报网格（电影和剧集一起，卡上只有画面）；「播放 / 想看」在长按菜单里（C21、C45）。想看、继续观看、最新加入这些整页清单是同样的网格。
- 合集页 `CollectionPage`（五个大类、某一类、精选电影、精选剧集；用户要求，照 Apple「游戏」App 的合集页）：整页最顶上一片主色（第一部海报的色相）往下沉到黑，铺到状态栏、导航栏和侧边那一列底下（F6）；三张立体海报（`PosterFan`，减弱动态效果时不弹不浮：F59）；大号粗体标题 + 一句灰字；一列宽银幕大卡，卡底一条从画面取色的实色条（小海报、「Cuven 独占」、片名、简介第一句、「查看」），整张卡点进详情、从卡上放大出来（F57），长按是「播放 / 想看」（C21、C45）；宽的屏一行两三张（S1）。有意的偏离：大标题由页面自己画在海报下面，导航栏里先只有返回钮、滚过大标题才出现标题（偏离 C13 的系统大标题）；「查看」只是样子，点的是整张卡。
- 文件夹页：大标题、一排子文件夹（系统的文件夹图标 + 名字）、海报网格（T23）。

### 账户
- 账户与设置不是标签：主页标题那一行右边一枚头像，点开是弹层（用户要求，头像从侧边导航里分出来；和 App Store、Apple TV 右上的账户钮一样），右上系统的玻璃关闭钮（C14、C53）。
- 版式照用户给的参考图（Apple「游戏」App 的个人页），不再是系统 `Form`：底从头像取主色、往下渐暗到深灰；头部居中头像 + 名字（Large Title 粗体）+ 一颗玻璃「个人档案」胶囊钮；每组一行粗体组名（Title 2）+ 一张圆角 26 的半透明卡，一行一项：灰色符号、标题（Title 3）+ 灰色说明（Callout）、行尾「›」/ 开关 / 数值，行与行之间一条细线；整行可点、按下垫一层淡白（F74、C31）。字号都跟着动态字体走（F17）。

### 登录
用户要求「登录应该和 web 端一模一样」：这一页照网页版 `#cvlHost` 逐项重做，下面这些都是**有意偏离 HIG 的地方**（以前按 HIG 做的深色一列、系统导航栈、字段标签都拿掉了）：
- 底图是网页版「Sky Pro 流体」着色器逐行移植（`SkyFluid.metal`，参数、配色、CSS 滤镜都一样），0.9 秒淡入，上面一层暗幕；装饰动画（F38、F80）照网页版保留：打开时、登录成功时蓝色光晕和光环从「Cuven max」字标往外扩。
- 下半截是一整张白色圆角面板（上圆角 40；宽屏收成居中的卡、矮横屏品牌区压扁），在全 App 的深色里是一块浅色岛（面板里用浅色外观，键盘也是浅色）。
- 字段没有上面那一行标签，只有框里的提示（偏离 C105）；没有清除钮（C108）；密码框只在认出「有密码的账户」时才展开。
- 一张面板里六页交叉淡入淡出，不用系统导航栈，也没有右滑返回（偏离 C14、F53）；左上一颗网页版的圆形返回钮，只在电子邮件 / 验证码 / 设定密码三页出现。
- 主按钮是黑色胶囊、忙的时候换成网页版的 12 辐条转子；状态行一句话、只靠颜色区分（蓝 = 认出账户、绿 = 成功、红 = 出错），不加符号（偏离 F36、F87）。
- 进来不自动弹键盘（网页版：一进来就弹，屏幕会先被顶一下再回落）；输入法弹起时面板整体上移、底边骑在键盘上沿。
- 仍然守住的：键盘类型和自动填充类型对得上（账户 `.username`、电子邮件 `.emailAddress`、密码 `.password` / `.newPassword`、验证码 `.oneTimeCode`，整段粘贴也行：C107、C111、C112）；要的数据没填好时主按钮是灰的（C110）；「减弱动态效果」时不放脉冲、不呼吸、成功页直接出现（F59）。
- 面容 ID：和网页版一样，只在建立账户的最后一步问一次（这台设备没有可用的生物识别就跳过这一页）；以后在账户页开关。登录页上「使用面容 ID 登录」只在本机为这个账户开过时出现，按钮写明是哪一种（触控 ID 的设备写触控 ID：C100、C101）。

### 弹层、欢迎、隐私、播放加载
- 「更多」一律是系统 `Menu`（无边框的 `ellipsis`），确认用 `.confirmationDialog`；不再用自绘的底部弹层（C11、C15、C44–C48）。
- 全部演员：`.medium` / `.large` 的弹层，点演员在弹层里推进去，不叠第二层弹层（C50、C51、C54、C56）。
- 欢迎页最多出现一次（第一次登录后），不每次启动都挡着（C72、C75、C76）。
- 隐私同意每个版本只问一次；通知权限挪到有人打开「新片上架通知」的那一刻再问（C78、C79）；不画拖不动的把手（C51）。
- 播放加载（用户要求，和网页版一模一样；有意偏离 C90、C68）：点下去就出现，一整个顶层窗口盖住一切直到首帧：极光背景（网页版 Aurora 着色器逐行移植到 `Aurora.metal`，同样 25% 分辨率、手指按住时光带绕着手指转）、「Cuven max」、按真实阶段推进的胶囊进度条（网页版的跟随公式：不倒退、开播前不走满）、模糊轮换的提示、左上关闭钮（F74）；减弱动态效果时极光停住（F59、F60）。
- 标签栏不在滚动时缩小（没有附件时 HIG 不这么做：C10）；设置里不重复系统已有的开关（C95）。

## iPhone Duo 展开（tvOS 风格）
- 不是另一套界面：同一套部件按 `DSMetrics` 长大（S1、D2）——头图更大、每排 4（竖）/ 6（横）张海报、标题上一级字号、边距与间距按 tvOS 比例（S3–S6）。
- 系统栏由系统摆（D5–D7）：展开竖拿是横向的栏，横拿和外屏在侧边一列；画面在栏下延伸（F6、S19）。
- 一处有意的偏离（用户要求）：折起（横竖都算）和展开横拿时，系统把标签栏竖进侧边那一列，搜索和别的格挤在一枚胶囊里、SwiftUI 拆不开；这几种形态下收起系统标签栏，在那一列里自己画一枚竖向 Liquid Glass 胶囊（主页 / 资料库，只有图标，选中那格垫一块更亮的玻璃、滑过去）和下面单独一颗搜索圆钮（`DuoNav.swift`）——和 iOS 26 横着的标签栏把搜索拆出来是同一个样子。导航栏、工具栏和返回仍是系统的；展开竖拿和别的 iPhone 仍是系统标签栏（偏离 D7）。
- 展开时卡更大、间距更宽（卡间距至少 24），视差按卡宽算（S12）；头图铺满到侧边那一列底下（F6）。
