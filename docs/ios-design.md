# Cuven max（iOS）设计规范：依据 Apple Human Interface Guidelines

所有界面改动先查 Apple 文档、有出处再动手。出处编号：

- **F1–F90**：[docs/hig/foundations.md](hig/foundations.md)（布局、字体、颜色、深色、材质与 Liquid Glass、动效、图像、无障碍、品牌与文案）
- **T1–T40 / D1–D18 / I1–I14 / S1–S24**：[docs/hig/tvos-and-duo.md](hig/tvos-and-duo.md)（tvOS 设计语言、iPhone Duo 的约束、iOS 通用规则、把 tvOS 搬到触屏上的做法）
- **C 编号**：组件与模式（标签栏、工具栏、列表、弹层、菜单、搜索、引导、隐私、播放），见 [docs/hig/components.md](hig/components.md)

每条规则都附了 Apple 原文的短引文和页面 › 小节。

## 原则

1. **内容在前，界面退后**：画面铺满，字和控件只在需要时出现；品牌不占内容的位置，不放口号、印章、法务行（F1、F80、T1）。
2. **一套设计随屏幕长大**：折起和展开是同一套 tvOS 式的语言（头图、货架、焦点、视差），展开只是更大——更大的头图、每排更多的卡、更从容的留白；不另做一个「展开模式」（S1、D2、D3、I11）。
3. **玻璃只在功能层**：标签栏、导航栏、工具栏、少数浮在画面上的控件；卡片、货架、文字面板一律不用玻璃（F38–F46）。
4. **分组靠留白**：不画描边、不垫底板、不用分隔线分区；同一种间距贯穿全 App（F3、F12）。
5. **系统字、语义色**：一律用系统文字样式（Large Title … Caption 2），层级靠字重和 `.secondary`；强调色只给一个主操作和状态（F15–F19、F28、F32、F33）。
6. **动效有目的**：焦点（停在左侧基准线上的卡微微放大、阴影加深、标题浮现）、画面视差、头图翻页、系统的推入 / 缩放转场；「减弱动态效果」打开时放大、视差、自动翻页都停（F52–F61、S7–S14、S17）。
7. **文案短而平实**：按钮用动词（播放、继续播放），不写「我们」，空状态告诉人下一步（F84–F88）。

## 设计系统（`ios/Cuven/UI/Design.swift`）

| 部件 | 做什么 | 出处 |
|---|---|---|
| `DSMetrics` | 边距、卡间距、排间距按 tvOS 的 80 / 40 / 100（以 1920 宽为准）缩到当前宽度，再以 iPhone 系统边距兜底；海报每排 3（折起）/ 4（展开竖）/ 6（展开横）张，16:9 卡 1 张多 / 2 / 4 张 | S3、S5、S6、F9、D4 |
| `DSSection` / `DSShelfTitle` / `DSShelf` | 分区标题（折起 Title 3 半粗、展开 Title 2 粗，和卡同一条左边线，有去处时带「›」）＋ 一排卡（停在左侧基准线、右边露出下一张一条） | F2、F86、T23、T25、S8、I13 |
| `DSPosterLockup` / `DSWideLockup` | tvOS 的 lockup：画面 + 卡下字。停在基准线上的那张以中心放大（海报 ≤1.14、16:9 ≤1.09，两边长出的不超过卡间距）、阴影加深；海报的字只在焦点那张浮现，16:9 的字一直在；画面在卡里有约 3% 的视差 | T20、T22、T27、S9、S12、F61 |
| `.dsPlay` / `.dsSecondary` | 主操作白色胶囊黑字（tvOS 聚焦按钮的样子）；次操作半透明材质；都至少 44 高 | S17、F74 |
| `DSHeroCarousel` | 全屏轮播头图：画面在后、字在前（两层视差），左下角字标、一行信息、播放 / 详情；没碰时 7 秒翻一页，一碰就停；减弱动态效果或旁白开着时不翻 | T30–T32、S15–S17、F59、F79 |

## 各页

### 主页
- 头图 `DSHeroCarousel`：竖拿约 70% 屏高、用竖版全屏图；横拿 16:9（S15）。系统栏浮在画面上（F6）。点画面或「详情」进详情，详情页从这张画面上放大出来、返回时缩回（T31、F57）；字标与那一行字不接手势，点在字上也是点画面。
- 分区（只靠留白分开）：继续观看（16:9，带进度）→ 今日推荐（海报，名次写在卡下的字里）→ 最新加入（16:9；新入库的左上角一枚「新」，是状态色 F32）→ 剧集（16:9）→ 各年份（海报，标题「2026 ›」进年份页）→ 文件夹。
- 去掉：分区玻璃胶囊、年份玻璃条、品质保证章、描边大数字、分隔发丝线、「Cuven TV 严选影片」、「没有更多了」占位卡（F3、F38、F80）。

### 详情（电影 / 剧集）
- 头部全幅画面（竖拿竖版全屏图、横拿 16:9），底部渐暗，左对齐：字标、一行信息（类型 · 年份 · 片长 · ★评分）、播放 + 一颗「…」系统菜单（从头播放、复制直链、分享）（F1、F34、S17、F50）。
- 下面：简介（Body，宽松行距，三行后「更多」：F21、F24）→ 分集（剧集：16:9 卡一排，季在分区标题的菜单里）→ 预告片（有就有）→ 演员（圆形照片 + 名字 + 角色：T21 monogram）→ 信息（几行左灰右白的字：类型、年份、片长、评分、导演、格式）。
- 去掉：「尖端色彩和画面质量技术」与「语言」两块玻璃卡、法务一行、品质保证、「第 N 幕」（F38、F80、F84）。

### 资料库
- 保留电影感的展映（满屏画幅、钉住、收回 16:9、静音预告片），但每章只留画幅、字标、一行信息、简介（三行）、播放 / 详情两颗钮；去掉评分胶囊、演职员一行、剧照排、副标题口号（F80、F3）。

### 搜索 / 年份 / 文件夹
- 搜索：系统搜索栏与大标题；没输入是「最近添加」海报网格，输入了按类型分区、每区一排同样的卡，最相关的那一类在前（T23、F4）；没结果用系统的空状态（F87）。
- 年份页：系统大标题 + 副标题「N 部影片」，系统列表一行一部（小海报、片名、一行灰字、行尾 ›），「播放 / 想看」在长按菜单里，不再有行尾「…」和自绘弹层（C21、C29、C31、C45）。整页清单（今日推荐等）同样的列表，今日推荐行首是名次。
- 文件夹页：大标题、一排子文件夹（系统的文件夹图标 + 名字）、海报网格（T23）。

### 账户
- 「账户」是一个标签（不再在顶栏放头像钮）；系统 `Form` + 分组样式（C30、F14），顶上头像、名字、邮箱。

### 登录
- 整屏、深色：没有账户什么都看不了，所以登录不往后推（C98）；一列居中，展开的 Duo 上不超过 440 宽（F8），只靠留白分组（F3、F12）。不放背景光斑、白色面板、玻璃和装饰动画，品牌只留一枚 56 点的小图标（F38、F80）。
- 大标题「登录」+ 一句「使用你的 Cuven 账户登录 Cuven max。」；页脚一句为什么要账户、账户还能登录哪些服务（C98）。
- 字段：上面一行标签、框里一句提示（C105），竖排、同宽、同样的间距（C109）。账户字段用邮箱键盘和 `.username`，电子邮件 `.emailAddress`，密码是 `SecureField` + `.password` / `.newPassword`、从不预填（C106、C107）；验证码字段是 `.oneTimeCode`，短信 / 邮件里的验证码和整段粘贴都能直接填进来（C111、C112）；账户和电子邮件字段尾部一颗清除钮（C108）。
- 每一步一颗白色主按钮，要的数据没填好时是灰的（C35、C110），忙的时候按钮里转圈（C66–C69）；其余都是纯文字按钮。出错写在字段下面，红字加一枚符号（F36、F87、C83）；新密码在输入时就核对，还在写时是灰字提示，离开字段还不对才变红（C110）。
- 一步一页，用系统的导航栈推进：系统返回钮、右滑返回（C14、F53）。设定密码那一步左上是「取消」（整段作废、回到登录）；启用面容 ID 和完成两步已经验证过身份，不能再退回去。
- 生物识别：按钮写明方法（「使用面容 ID 登录」），设备上是触控 ID 就写触控 ID，没有就不出现（C100、C101）。账户页「使用面容 ID 登录」的开关和 C102 有出入：它同时决定要不要把登录身份存进受生物识别保护的钥匙串，先保留。

### 弹层、欢迎、隐私、播放加载
- 「更多」一律是系统 `Menu`（无边框的 `ellipsis`），确认用 `.confirmationDialog`；不再用自绘的底部弹层（C11、C15、C44–C48）。
- 全部演员：`.medium` / `.large` 的弹层，点演员在弹层里推进去，不叠第二层弹层（C50、C51、C54、C56）。
- 欢迎页最多出现一次（第一次登录后），不每次启动都挡着（C72、C75、C76）。
- 隐私同意每个版本只问一次；通知权限挪到有人打开「新片上架通知」的那一刻再问（C78、C79）；不画拖不动的把手（C51）。
- 播放加载：加载超过 2 秒才出现，黑底、居中一个系统转圈，开播即消失；不放动画背景、口号与假进度（C90、C68、C69）。
- 标签栏不在滚动时缩小（没有附件时 HIG 不这么做：C10）；设置里不重复系统已有的开关（C95）。

## iPhone Duo 展开（tvOS 风格）
- 不是另一套界面：同一套部件按 `DSMetrics` 长大（S1、D2）——头图更大、每排 4（竖）/ 6（横）张海报、标题上一级字号、边距与间距按 tvOS 比例（S3–S6）。
- 系统栏由系统摆（D5–D7）：展开竖拿是横向的栏，横拿和外屏在侧边一列；画面在栏下延伸（F6、S19）。
- 焦点、视差、头图翻页在展开时幅度更从容（卡更大，放大与视差都按卡宽算：S9、S12）。
